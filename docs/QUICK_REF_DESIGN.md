# Quick Ref: Design System

## Font Scale (4 sizes)
| Size | Weight | Use |
|------|--------|-----|
| 14px | 600 | Headings (h3) |
| 13px | 400 | Body text, inputs |
| 12px | 400 | Labels |
| 11px | 400 | Captions |

## Spacing (8px baseline)
4px internal | 8px between | 12px sections | 16px major

## Buttons (Unified)
All: **8px 14px** padding | **13px** font | **4px** radius

## Components
- **Drop zones:** 120px height
- **Textareas:** 60px min
- **Modal buttons:** flex: 1, 12px 16px

## Border & Shadow
- **Radius:** 4px (small) | 6px (large)
- **Shadows:** 2 levels (subtle → medium)

## Colors
Primary: #0066cc | Danger: #dc3545 | BG: #f5f5f5  
Text: #333 (dark) | #666 (medium) | #999 (light)

## Responsive
- Desktop: 2 columns
- Tablet (768px): Stacked
- Mobile (480px): Single column

## Accessibility
✅ Contrast 4.5:1+ | ✅ Touch 44px+ | ✅ Focus visible | ✅ Hierarchy clear
